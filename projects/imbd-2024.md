- 我的分工：資料增強（切分、翻轉、平衡各類樣本）與訓練相關腳本（`preprocess.py / train.py / test.py / inference.py`）
- 來源：決賽團隊測驗報告簡報

## 題目
工業產品表面影像四分類：Type0 無瑕疵、Type1 角落／邊緣損傷、Type2 長刮痕、Type3 不規則損傷。

## 資料與前處理
- 原始分布嚴重不平衡：Type0 75,570 / Type1 2,400 / Type2 22,392 / Type3 30,855 張
- 切 25% 為驗證集；Type0 隨機抽 30,000 張；Type1、Type2 對訓練集做資料增強使各類接近
- 增強只用翻轉、180° 旋轉與「對切後翻轉半邊」，刻意不縮放、不隨機裁剪，避免破壞邊緣／刮痕特徵
- 增強後訓練集：30,000 / 21,600 / 28,794 / 23,142

## 模型
- 參考 VGG 的較淺 CNN：3 個 Conv Block（各 2 層 3×3 Conv + BatchNorm + ReLU + MaxPool）+ FC Block（3 層全連接 + Dropout + LogSoftmax）
- PyTorch 訓練；Pillow 做影像處理；sklearn 算混淆矩陣
- 提供 `preprocess.py / train.py / test.py / inference.py` 四支腳本

## 結果
- Training_1 隨機 25% 測試：**F1 = 0.99413**
- Training_2 全部當測試：**F1 = 0.99377，Accuracy = 0.99565**

## 技術
PyTorch, CNN, 資料增強, 類別不平衡處理, Pandas, Pillow
